# Víme, co dělat

Nezávislý český web o připravenosti domácností na vážnou krizi, včetně možného vojenského konfliktu na východní hranici NATO, a o odolnosti vůči manipulaci. Navazuje na státní [72h.gov.cz](https://www.72h.gov.cz/cs) a přidává scénář, příběhy a předběžné očkování proti propagandě.
